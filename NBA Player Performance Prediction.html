Project : Extended NBA Player Performance Analysis Using Python¶

Dataset: NBA Players Dataset (all_seasons.csv)

Background and Problem Definition¶

For this Project, I extended my Project 'An Analysis of Factors Influencing NBA Player Performance' topic by analyzing NBA player performance using Python instead of R. The goal of this project is to use pandas for data manipulation, matplotlib for visualization, and simple machine learning tools from scikit-learn to better understand which factors are related to NBA scoring performance.

NBA teams use data analysis to evaluate players, compare performance, and make decisions about player development. In this project, I focus on player-season statistics such as points, rebounds, assists, true shooting percentage, usage percentage, age, height, and weight.

Data Source and Citation¶

The dataset used in this project is the NBA Players Dataset from Kaggle. It contains player-season data for NBA players, including demographic variables and performance statistics.

Source: Kaggle - NBA Players Dataset by Justinas Cirtautas
URL: https://www.kaggle.com/datasets/justinas/nba-players-data

Research Questions¶

  1. What is the distribution of NBA players' points per game?
  2. Is there a relationship between usage percentage and points per game?
  3. Does shooting efficiency, measured by true shooting percentage, influence scoring?
  4. How does scoring differ across age groups?
  5. How has NBA scoring changed over time?
  6. Which player attributes are most strongly correlated with scoring?
  7. Can player performance statistics be used to predict points per game?

4. Data Wrangling, Cleaning, and Feature Creation¶

For the cleaning step, I remove the unnecessary index column if it exists, convert height and weight into more familiar units, create age groups, and extract the starting year of each NBA season. I also filter out players who played fewer than 10 games and remove invalid shooting or usage percentage values. This helps reduce noise from players who barely appeared during a season.

In [6]:
nba_clean = nba.copy()

# Remove extra index columns if they exist
nba_clean = nba_clean.drop(columns=[col for col in nba_clean.columns if "Unnamed" in col], errors="ignore")

# Create easier-to-interpret variables
nba_clean["height_inches"] = nba_clean["player_height"] / 2.54
nba_clean["weight_pounds"] = nba_clean["player_weight"] * 2.20462
nba_clean["season_start"] = nba_clean["season"].str[:4].astype(int)

# Create age groups
nba_clean["age_group"] = pd.cut(
    nba_clean["age"],
    bins=[0, 24, 29, 34, 100],
    labels=["Under 25", "25-29", "30-34", "35+"]
)

# Filter data to keep meaningful player-season records
nba_clean = nba_clean[
    (nba_clean["gp"] >= 10) &
    (nba_clean["ts_pct"] > 0) &
    (nba_clean["ts_pct"] <= 1) &
    (nba_clean["usg_pct"] > 0)
].copy()

Exploratory Data Analysis¶

Q1. What is the distribution of NBA players' points per game?¶

This question examines how scoring is distributed among NBA players. A histogram is useful here because it shows whether most players score similar amounts or whether only a small group of players score at a high level.

In [12]:

Q1 Interpretation¶

The histogram shows that points per game is right-skewed. Most NBA players score a smaller number of points per game, while only a smaller group of players average high scoring totals. This makes sense because NBA teams usually have only a few main scoring options, while many players have smaller offensive roles.

Q7. Can player performance statistics be used to predict points per game?¶

For the final question, I build prediction models using player statistics as input variables. This upgrades the project from only exploratory analysis to a simple machine learning task. I use both a linear regression model and a random forest model, then compare their performance using RMSE and R-squared.

  • RMSE measures the typical prediction error in points per game. Lower RMSE is better.
  • R-squared measures how much variation in points per game is explained by the model. Higher R-squared is better.
In [22]:
features = [
    "usg_pct", "ts_pct", "gp", "age", "height_inches",

X = nba_clean[features]

Final Conclusion¶

This project used Python to analyze factors influencing NBA player scoring performance. The analysis showed that points per game is not evenly distributed across players; most players score modestly, while a smaller number of players are high-volume scorers. Usage percentage had one of the strongest relationships with points per game, which makes sense because players who are more involved in their team's offense usually have more chances to score.

True shooting percentage also had a positive relationship with scoring, but efficiency alone was not enough to explain scoring output. Age group comparisons suggested that players in their prime years tend to have higher scoring averages. The time trend analysis showed how scoring has changed across NBA seasons, giving context to how the league has evolved.

The predictive modeling section showed that player statistics can be used to estimate points per game. The random forest model and linear regression model both provided useful results, and the feature importance analysis helped identify the variables most connected to scoring.

Overall, this project demonstrates how pandas, matplotlib, and machine learning tools in Python can be used to clean data, explore patterns, create visualizations, and answer real-world sports analytics questions.

Limitations¶

There are a few limitations in this project. First, the dataset is based on season-level statistics, so it does not include game-by-game context. Second, the dataset does not include every factor that affects scoring, such as injuries, team strategy, opponent defense, or player position. Finally, correlation and prediction models can show relationships, but they do not prove direct causation.
